  • 銀行「現鈔賣出」：你用台幣向銀行買外幣現金；不是即期匯率。
  • SuperRich「買入」：你把外幣現金交給換匯店，換匯店買入外幣並給你泰銖。
  • 美元限 100 美元鈔、歐元 100–500 歐元鈔、日圓 5,000–10,000 日圓鈔、人民幣限 100 元鈔、韓元採非 1,000 元小鈔的牌告；實際不同面額可能有價差。
  • 本工具採比例換算，未模擬整張紙鈔、找零與門市庫存；實際可換金額應以臨櫃確認為準。
  • GitHub Actions 會分別嘗試官方與第三方來源。官方失敗時顯示「官方取得失敗」，不以鏡像取代官方牌告；第三方數字在下方獨立參考區。
